# Yagona tizim

Integrated Qualifications & Labour Market Platform — malakalar va mehnat bozori yagona platformasi.

Platforma bitta `index.html` faylidan iborat (barcha skript, uslub va demo ma'lumotlar ichida), shuning uchun uni ochish uchun server kerak emas.

## Ishga tushirish

- Faylni yuklab olib, brauzerda `index.html` ni oching, yoki
- GitHub Pages orqali: **Settings → Pages → Branch: main / (root)** ni yoqing, sayt `https://nqaae-monitoring.github.io/Yagona-tizim/` manzilida ochiladi.
